### How I build

*Source: Stated, except the share of commits authored through AI agents, which is Measured*

**AI native delivery.** I orchestrate AI coding agents (Claude Code and others) as the primary implementation engine. Across my active portfolio, roughly three quarters of all commits were authored through AI agents under my direction. That is a discipline, not a shortcut: clear specifications, reviewable task boundaries, and a human owning architecture, data integrity and security.

**Owned architecture.** New products follow a consistent, intentional stack: a Next.js client, serverless API handlers on Vercel, and Supabase (Postgres) for auth and data with row level security. Schema changes are written as versioned migrations and secrets stay in encrypted environment variables.

**Shipped, not shelved.** The work below is iterated and deployed, not weekend demos. My deepest product carries nearly two hundred commits of real iteration.
